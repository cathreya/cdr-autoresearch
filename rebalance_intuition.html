Merge Intuition for Cyclic Rebalancing

Rule Being Visualized

For every subsegment from the removed node, choose the target segment whose new storage set overlaps the old source storage set as much as possible. The subsegment superscript is the set of new nodes that must receive it: S~_j \ S_i. When a corner case would overload a target, the small pieces are spread to keep target segment sizes balanced.
